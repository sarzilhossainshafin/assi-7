# বাজার দর | BazarDor

**BazarDor** is a web application that helps users easily check daily prices of essential grocery items in Bangladesh. Users can explore market prices, compare price changes, and find important pricing information in one place.

## Technologies Used

- **Next.js** — React framework for building the web application
- **React** — Component-based user interface
- **TypeScript** — Type-safe JavaScript development
- **Tailwind CSS** — Responsive and modern UI styling
- **MongoDB** — Database for storing and managing product data
- **REST API** — Fetching product and market price information
- **Better Auth** — User authentication
- **ESLint** — Code quality and linting

## Key Features

1. **Daily Market Prices** — View the latest available prices of essential grocery items.
2. **Price Increase and Decrease Tracking** — Explore products whose prices have increased or decreased.
3. **Product Categories** — Browse products by category to find items easily.
4. **Product Details** — View individual product information, including price, unit, and price changes.
5. **User Authentication** — Sign up and sign in to access account-related features.

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed on your computer.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ProgrammingHero1/B14-A7-Bazar-Dor.git
   ```

2. Navigate to the project directory:

   ```bash
   cd B14-A7-Bazar-Dor
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure the environment variables in your `.env.local` file as required by the project.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open [http://localhost:3000](http://localhost:3000) in your browser.
